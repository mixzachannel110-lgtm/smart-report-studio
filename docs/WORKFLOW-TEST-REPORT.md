# รายงานทดสอบเส้นทางการใช้งาน IDC Smart Report Studio

วันที่ 1 พฤศจิกายน 2569 · ต้นแบบรุ่น 0.1

## สรุปผล

ตรวจการทำงานของโค้ดตามเส้นทางผู้ใช้ผ่านการเรียกหน้าจอ ฟอร์ม และเหตุการณ์ของแอปในสภาพแวดล้อมจำลอง ผลผ่าน **37/37 กรณี** และตรวจ JavaScript syntax ผ่าน คำว่า “ผ่าน” ในรายงานนี้หมายถึงตรรกะและข้อมูลที่แอปสร้างได้ใน test harness ยังไม่ได้ยืนยันการแสดงผลจริงใน Chrome, Local Server, IndexedDB ของ Browser จริง หรือไฟล์ PDF ที่บันทึกจากหน้าต่างพิมพ์

## เส้นทางที่ทดลองในโค้ด

| ขั้น | สิ่งที่ทำในการทดสอบ | สิ่งที่เปลี่ยนตามข้อมูล |
|---|---|---|
| เปิด Dashboard/เมนู | แสดง HTML ของ 15 หน้ามุมมองในพื้นที่จำลอง | แถบเมนู ระบุหน้า และโครงการที่เลือก |
| สร้างโครงการใหม่ | เริ่มจากข้อมูลอุปกรณ์ตัวอย่างและล้างค่าผลตรวจ | ลูกค้า/สถานที่/รหัสวันที่ เป็นข้อมูลของโครงการใหม่; Answers และ Tests เริ่มว่าง |
| กรอกชื่อลูกค้า | ส่งเหตุการณ์ input จริงให้ Listener ของแอป | ชื่อใหม่แสดงบนปก Classic Preview |
| ตอบแบบตรวจ N และใส่เหตุผล | ส่งเหตุการณ์ click และ input เข้าระบบ | ผล N และข้อความปรากฏในตารางตรวจ ไม่เปลี่ยนเป็นปกติ |
| เพิ่มรูป | ส่ง Image Blob ตัวอย่างเข้าฟังก์ชัน Upload, สร้าง SHA-256 และบันทึกผ่าน IndexedDB test double | รูปถูกผูก project_id ปัจจุบัน; รูปซ้ำถูกข้าม; รูปใหม่ผ่านกฎตรวจหลักฐาน |
| ตรวจภาพจาก PDF เดิม | ใส่รูปที่มี `source:true` เข้า Model Validation | รูปเดิมไม่ผ่านเงื่อนไขภาพหลักฐานของงานใหม่ |
| กรอกค่าทดสอบ | บันทึก 744 GPM, 86 PSI, −6 PSI ณ 100% | ตารางและกราฟใช้ค่าปัจจุบันร่วมกัน; จุดที่ไม่มีค่าหรือไม่ได้ทดสอบไม่ถูกวาด |
| เลือก 150% ไม่ได้ทดสอบ | บันทึกสถานะพร้อมเหตุผลโดยให้ค่าตัวเลขว่าง | ตารางแสดงข้อความไม่ได้ทดสอบ; ไม่สร้างศูนย์หรือจุดกราฟขึ้นเอง |
| สร้างงานจากเก่า | เรียกการทำงาน Clone Project | ข้อมูลอุปกรณ์ถูกเก็บ; คำตอบ ผลทดสอบ รูป และ Snapshot ของรายงานใหม่ว่าง |
| เปิด PDF เทียบ | เรียกปุ่มเทียบต้นฉบับทั้งสองเทมเพลตและเลือกหน้าที่ 43 | URL เปลี่ยนไปยัง PDF ของครัวการบินหน้า 43; AGC ใช้ไฟล์อีกฉบับและมี 44 หน้า |
| ตรวจรายงานครบถ้วน | เรียก Model Validator กับข้อมูลว่าง | คืนลิงก์ไปแบบตรวจ ค่าทดสอบ ข้อมูลโครงการ รูป และสรุปที่ยังขาด |
| ส่งตรวจ/ล็อก/สร้าง Revision | ทดลองเปลี่ยนสถานะและ Snapshot | Snapshot เก็บสำเนาเดิมเมื่อ Revision ใหม่เปลี่ยนข้อความ |

## ตรวจสองเทมเพลตและข้อมูลผิดพลาด

- แยกไฟล์ PM-FP-001 และ PT-FP-001 พร้อม PDF อ้างอิงต้นฉบับครบ 56/44 หน้า และ Geometry ของหน้า 100 หน้า
- ข้อมูลชื่อลูกค้ากับรหัสงานใหม่มาแทนค่าบนปก ส่วนภาพลายเซ็นและ PDF ทั้งเล่มเก่าไม่ถูกฝังใน HTML ของรายงานที่สร้าง
- ข้อความจากผู้ใช้ Escape ก่อนแสดงผล ทดสอบกรณี `<script>` และ `<img>`
- `NOT_TESTED` ไม่มีตัวเลขได้เมื่อใส่เหตุผล; `TESTED` ต้องมีตัวเลขครบ; ค่าศูนย์ที่วัดจริงยังแสดงเป็นศูนย์
- ตารางและกราฟไม่มีเส้นลากผ่านจุดที่ทดสอบไม่ได้
- การตรวจหน้า 37–43 ของ PDF AGC อ้างอิง Geometry สแกน A4 ไม่บังคับเป็น Letter

## สิ่งที่ต้องทดลองบนเครื่องจริง

ยังเปิด Browser QA ไม่สำเร็จในเครื่องที่สร้างต้นแบบ: Python Local Server ถูกระบบปฏิเสธการ bind ที่ 127.0.0.1 และการเริ่ม Chrome Headless ปิดตัวก่อนสร้างภาพหน้าจอ จึงยังไม่มีหลักฐานการวัดภาพหน้าจอและ Pagination

ให้ทดสอบต่อบนเครื่องใช้งานด้วย Chrome: เปิด `dist/index.html` → สร้างโครงการ DEMO → เพิ่ม JPG/PNG → กรอกแบบตรวจหนึ่งข้อเป็น N → บันทึกผล Flow 100% → ตรวจหน้า Cover/Inspection/Performance/Appendix → เปิด PDF ต้นฉบับ → Print เป็น PDF แล้วตรวจทุกหน้าก่อนใช้ข้อมูลจริง ทดสอบ Edge Cases อย่างชื่อลูกค้ายาว รูปใหญ่ รูปผิดชนิด และการปิด/เปิด Browser อีกครั้งด้วย
